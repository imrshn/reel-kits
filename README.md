# Reel kits

Free kits from my Instagram Reels. Commented a keyword? Your kit is below. Each one is a ready-made folder you open in the Claude desktop app (Code tab).

| Keyword | Kit | What it does | Download |
| --- | --- | --- | --- |
| EDITOR | [Claude Video Editor](kits/editor) | Turns a raw clip into a captioned, ready-to-post vertical Reel | [editor-kit.zip](https://github.com/imrshn/reel-kits/releases/download/editor/editor-kit.zip) |

**How to use any kit:** download the ZIP, unzip it, open the folder in Claude's Code tab (Local session), and follow `START HERE.md`.

Most kits need a paid Claude plan (Pro or higher) and a Mac or Windows laptop.

---

<sub>Maintainers: each kit lives in `kits/<name>/` with a `kit.json`. Pushing to `main` rebuilds its ZIP and replaces the file behind its permanent download link (see `.github/workflows/release-kits.yml`).</sub>
