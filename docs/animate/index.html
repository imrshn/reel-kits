From the reel

The workflow

  1. 1
    Get the Claude desktop appSkip the browser. Download it from claude.ai/download and sign in. Claude Code needs a paid plan (Pro or higher).
  2. 2
    Download the kit and unzip itYou get a folder called AI Video Editor. Put it on your Desktop. Your skill files and every finished reel live here.
  3. 3
    Start a Claude Code chat on that folderCode tab → new session → choose Local → select the AI Video Editor folder.
  4. 4
    Type check my setupClaude installs what's missing inside the folder (no password) and tests itself on a sample reel. Click Allow when it asks. About 10 minutes the first time.
  5. 5
    Type what the reel is about, in one lineFor example: make a reel about why airplane food tastes so bland. It writes the script, records the voiceover, animates every scene, times the captions and checks its own frames.
  6. 6
    Tell it what to changeLike you would a video editor. Every change saves a new version. See the fix lines.
Copy and paste

The prompts

Type these in the Claude Code chat inside the AI Video Editor folder.

01 · Setup

Check my setup

Check my setup. Install anything that's missing inside this folder, then test it by rendering the sample reel. Tell me in plain words when it's ready.
02 · Make

Make a reel from one line

Make a reel about [your topic in one line]. About [30] seconds. End with: [Follow for more / Comment KEYWORD and I'll send you ...]
03 · Own voice

Use your own voice (optional)

Use my recording for the voice: [drag your audio file here]. Match the script to what I said, then re-time the captions and render again.
