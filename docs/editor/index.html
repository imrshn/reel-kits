The 3 prompts

Paste them into Claude's Code tab, in order, inside an empty folder.

01 · Setup

Install the tools

You're my video editor, working in this folder. Set up these tools for me:

- FFmpeg for cutting and exporting
- Whisper (faster-whisper) for captions
- yt-dlp for downloading reference videos
- HyperFrames and Remotion for motion graphics (optional, they need Node.js 22+)

Install the Python tools into a private .venv inside this folder so nothing system-wide changes. Check what's already installed first. Ask me before anything that needs my password. Then test each tool on a short sample clip and tell me in plain words what works and what doesn't. Don't change anything outside this folder.
02 · Taste

Teach it your style

Here are Reels I love:
[paste 3 to 5 links]

Download them into references/ (if a download fails, I'll drop the files in myself) and study them closely: the hook in the first 2 seconds, pacing and average shot length, caption style (font, size, position, words on screen, highlight colour), colours, graphics and music energy.

Write what you learn into style-guide.md and follow it on every edit from now on. Make my Reels inspired by them, not a copy. Never reuse their footage, graphics, text or music.
03 · Edit

Edit a raw clip into a Reel

Edit the newest clip in raw-footage/ into a vertical Reel (1080x1920, 30 fps) that follows style-guide.md.

- Transcribe it with Whisper using word timings
- Cut dead air, ums, retakes and pauses longer than half a second
- Burn in captions: 1 to 3 words on screen, key word highlighted, kept out of the bottom 20% of the frame
- Put a bold 3 to 7 word hook title on screen for the first 2 seconds, using my own words
- If there's a track in references/music, add it under my voice and lower it when I talk
- Normalise loudness to about -14 LUFS

Keep it under 60 seconds if you can. Look at a few frames of the result before you show me. Export to exports/ and tell me the length, what you cut and the hook you used.
