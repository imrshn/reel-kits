Ruflo

Adds 100+ specialised agents to Claude Code. They plan, write code, run tests and check security together, share memory and learn from each task.

About 2 minutes

The setup

  1. 1
    Install Node.js 20 or newerGet it from nodejs.org if you don't have it. Check with node -v in a terminal.
  2. 2
    Open your project folder in a terminalUse the folder you want the agents to work on.
  3. 3
    Run npx ruflo@latest initIt adds Ruflo's agents, memory and tools to that folder.
  4. 4
    Restart Claude Code in that folderClaude Code picks Ruflo up when it starts. Then give it a real task, like the prompt in the next tab.
Only want the Claude Code plugin? Run these inside Claude Code
/plugin marketplace add ruvnet/ruflo
/plugin install ruflo-core@ruflo
/plugin install ruflo-swarm@ruflo

Before you start

The fine print

The savings numbers are Ruflo's ownIts user guide says smart routing can cut API costs by up to 75% and stretch your Claude Code plan up to 2.5 times. Simple edits skip the AI entirely. Your results depend on the task.
Start smallRun it on a copy of a project or a fresh folder first, and read what it changed before you keep it.
Plugins run with your permissionsRuflo's mods aren't sandboxed, so its README asks you to read their code before installing.
