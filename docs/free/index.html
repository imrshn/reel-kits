The fine print

Free to use, not always free for companiesStirling PDF is free up to 5 users, and Chatwoot keeps some enterprise features paid. Check each project's LICENSE file before you use one at work.
Most of them run on your own machineThat's why your data stays yours. It also means you install and update them yourself. Each GitHub page has the install steps.
Star counts changeStars were counted on 6 Nov 2026. They only go up, so the order may shift.
